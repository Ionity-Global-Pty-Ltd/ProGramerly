Your whole dev environment, installed for you

ProGramerly provisions a complete development machine on Windows, macOS and Linux — runtimes, editors, SDKs, shells, databases and AI tooling — from one catalogue, in one run. Then it keeps everything in sync, watches the box from the tray, and repairs itself.

What it actually does

No wizards to babysit, no half-finished PATH. Pick a profile, press go, walk away.

A real catalogue

Over a hundred curated packages across runtimes, IDEs, shells, databases, embedded, ML and MCP tooling — resolved to winget, Chocolatey or Homebrew per machine.

Stays current

Checks GitHub Releases on its own schedule, verifies each download against the published SHA-256, and updates itself in place.

Watches the machine

A tray monitor for CPU, memory, disk and network, with live probing so you find out something broke before your build does.

Repairs itself

Registry repair, PATH reconstruction and a dry-run mode that shows exactly what would change before a single byte moves.

AI tooling, first class

The AI profile brings MCP servers, model runners and agent tooling in one pass instead of a weekend of README archaeology.

Zero runtime dependencies

Node standard library only. Nothing to audit but the code you can already read, under Policy 986 AED.

Downloads

Every build is produced on GitHub's own runners — Windows on windows-latest, macOS on Apple's toolchain, Linux on ubuntu-latest — and published with a SHA256.txt you can check before you run anything.

Builds are currently unsigned: Windows shows “Windows protected your PC” → More info → Run anyway, and macOS asks for right-click → Open the first time. On Linux nothing gets in your way — mark the AppImage executable with chmod +x and run it, or install the package with sudo apt install ./programerly_*_amd64.deb / sudo dnf install ./programerly-*.rpm. Signing turns on automatically the moment the certificates are added to the repository secrets.
