**What is inside.** ProGramerly is the combined Ionity workstation: the Ai-OS operator
layout, live telemetry, the Ionity DOME - this machine as five strata and 24 segments,
each bound to a registered data set - fan control and CiC built in on Windows and
verified against their SHA-256 pins before they run, and local AI through Ollama with a
small default model (`llama3.2:1b`) that works on CPU.

## New in 3.3.0 - the local core on the deck

- **The machine reads itself on launch.** The local model reads the registered sets and
  reports on the deck, naming the model that answered, how many sets it could read and
  the tokens per second it managed. Any of the ten presets can be the standing question.
- **Ask in every workspace,** scoped to what that workspace covers - Hardware asks about
  thermal, Projects about repositories, Doctor about the last scan.
- **The orb.** The dock orb and the engine chip open all ten analysis presets, each with
  the question it will ask and the model that will answer. **Ctrl+/** runs the brief
  from anywhere.
- **Settings - Ionity DOME and local AI:** launch brief on or off and which preset, the
  local model, the dome re-read cadence, the shell accent, the Ionity mark, kiosk, and
  five actions - re-read the dome, write a DOME report to Markdown, open the report
  folder, open the fan profiles, open the data-set registry.
- **A dome that is on screen immediately.** The first pass skips any scan-cost set that
  is not already cached; the full pass - the drives, the listening ports, every
  repository under the development root - lands behind it and repaints. A segment that
  has not been scanned says so rather than being scored from nothing. Reads in flight are
  joined rather than started twice and every set a pass needs is read in parallel.
- **The shell has a colour.** Five accents drive the orb, the ask box, the chips, the
  brief and every primary control; each dome stratum carries its hue in the band, the
  legend, the meter and its segment icons; the gauges are coloured by what they measure.
  The transparent IONITY GLOBAL wordmark sits bottom left, and the intro assembles the
  dome arc by arc from this machine's own facts.

Nothing the model reads leaves the machine.

Windows builds are unsigned until a code-signing certificate is added to the repository
secrets, so SmartScreen shows "Windows protected your PC" - choose *More info > Run
anyway*. The SHA256.txt above lets you verify the file first.
