Fan control

Setting a fan curve means writing to the Super IO or embedded controller, and on Windows that needs a signed kernel-mode driver — which is exactly what FanControl and LibreHardwareMonitor ship, and why they exist. ProGramerly does not ship a kernel driver, and an app that claimed to set your curve without one would be lying to you. So it installs them, launches them, and reads their sensors above. The curve is set in the tool that owns the driver. That is the correct division of labour.

RGB lighting

A full implementation of the OpenRGB network protocol, spoken over TCP to a running OpenRGB server (127.0.0.1:6742 — switch it on in OpenRGB under Settings → General → Start server). That reaches motherboard 12 V headers, 5 V addressable headers, GPU, RAM, AIO pumps, fan controllers and peripherals, because OpenRGB already carries the per-vendor work and reimplementing it would be worse in every way.

Not connected.

Memory and cache

—

RAM flush calls EmptyWorkingSet on every reachable process — pages go to the standby list, where Windows can still reuse them. Purge standby list is the NtSetSystemInformation call RAMMap makes, which actually returns them to free; it needs administrator rights. Free memory is measured before and after both, so the number reported is measured, not claimed. Clear temp cache empties the OS temporary folder and nothing else — not browser caches, not package caches, not anything in a project.
